# دعوة تخرّج ريم العلي

**الرابط الحيّ:** https://claude.ai/artifact/GSoaw7wroiiey9jQUPfDPU
**النسخة في `src/`:** الإصدار `1792528657-4e4a` (٢٠ أكتوبر، v74 من الجلسة الأخرى) كما هو منشور، بملفاته الـ٩٢. لم يُعدَّل فيها شيء.

## الملفات
| الملف | المحتوى |
|---|---|
| `brief.md` | تفاصيل الحدث، الجمهور، الاستضافة، التفاعلات، المعلومات الناقصة |
| `design-decisions.md` | المعتمد والمرفوض والمعلّق، مع التصنيف وكلام نورة |
| `decision-history.md` | ما جُرّب وما قيل عنه بالترتيب |
| `design-system.md` | الألوان والخطوط والمواد والحركة وقواعد الأصول |
| `asset-manifest.md` | كل ملف: الغرض والأبعاد والخلفية والحالة والبرومبت إن وُجد، والأصل المطلوب توليده |
| `qa-report.md` | نتيجة فحص ٢٢ أكتوبر والمشكلات المقترح إصلاحها |
| `src/` | الدعوة القابلة للتشغيل |
| `assets/source/` | صور ChatGPT الأصلية قبل القص (البجعة، الظرف، البحيرة، التموّجات، زاوية القصب) |
| `tests/` | سكربتات الفحص وطريقة تشغيلها |
| `preview/` | لقطات الفحص ولقطات الافتتاحية |

## التشغيل محليًا
```bash
cd src && python3 -m http.server 8770
```
ثم http://127.0.0.1:8770/index.html

ملاحظة: زر «تقويم آيفون» يظهر فقط داخل عارض Claude، لأنه يحتاج صلاحية التنزيل من المنصّة.

## قبل أي تعديل
1. اقرأ أحدث نسخة من الرابط الحيّ كاملة. أكثر من جلسة تعدّل عليها.
2. حدّث `src/` منها إن تغيّرت، وسجّل ذلك في `decision-history.md`.
3. بعد التعديل: `tests/qa.js` ومقارنة الداخل بالبكسل.
4. لا نشر بدون موافقة نورة (حتى تحسم التعارض مع `CLAUDE.md`).
