# قرارات التصميم: دعوة ريم

> التصنيف حسب تعليمات الاستوديو: عام / خاص بالمشروع / رفض تنفيذ معيّن / مشروط / غير مؤكد.
> آخر تحديث: ٢٢ أكتوبر ٢٠٢٦.

## الهوية المعتمدة
لم تمر هذه الدعوة بجولة «أربع هويات» لأنها بدأت قبل تعليمات الاستوديو. الهوية الحالية اعتُمدت تدريجيًا بقبول نورة لكل مرحلة:
ورق كريمي، وأزرق الظرف، وبجع، وأسلوب الورق المقصوص الطبقي في الافتتاحية.

## معتمد

| العنصر | التصنيف | الدليل |
|---|---|---|
| لوحة الكريمي والأزرق الهادئ | خاص بالمشروع | النسخة الزرقاء من جلسة نورة، واستمرت بكل الجولات |
| الظرف الأزرق المنقوش بختم شمعي كريمي عليه بجعتان | خاص بالمشروع | معتمد منذ النسخ الأولى |
| فكرة «البجعة تجيب الدعوة» بأسلوب الورق المقصوص | خاص بالمشروع | قبلتها نورة وولّدت قطعها الأربع (١٩ أكتوبر) |
| زاوية القصب والريش الورقية للداخل | خاص بالمشروع | ولّدتها نورة بعد رفض النقش القديم (١٩ أكتوبر) |
| افتتاحية البجعتين والقلب والفيونكة | خاص بالمشروع، **غير مؤكد** | بنتها جلسة أخرى. لا أرى محادثتها فلا أعرف إن كانت نورة طلبتها أو وافقت عليها |
| بلا صوت | خاص بالمشروع | «الصوت محذوف بطلب نورة (١٨ أكتوبر)» في الكود |

## مرفوض

| العنصر | التصنيف | كلام نورة | السبب المعروف |
|---|---|---|---|
| الفيديو كافتتاحية | رفض تنفيذ معيّن | «ليش الفيديو يظهرلي ان لازم اشغله»، «ليش اختفى الفيديو» | الآيفون يمنع التشغيل التلقائي |
| انتقال المزج بين الافتتاحية والظرف | خاص بالمشروع، مرشّح عام غير مؤكد | «من الفيديو للظرف الحقيقي في ترانزشن مزج مو حابته مزعج» | تريد انتقالًا بلا مزج ظاهر |
| تغيّر الحجم أو القفز عند نهاية الافتتاحية | خاص بالمشروع | «تغيرت الواجهه فجأه ما ابي جذي» | تريد ثبات الحجم والموضع |
| واجهة البابين | رفض تنفيذ معيّن | «البابان ماعجبني»، «الواجهه مو عاجبتني ابي شي نفس الثيم بس يشد العين اكثر» | لا تشد العين بما يكفي |
| النقش الباروكي الجبسي في الزوايا | رفض تنفيذ معيّن | «مو عاجبني النقش على الزوايا»، «مو على ذوقي» | قصّ متّسخ، أسلوب ثقيل لا يناسب الورق المقصوص، يغطي أزرارًا |
| بدائل الافتتاحية الثلاثة الأولى من Claude | خاص بالمشروع | «الطريقه كامله ماعجبتني غيرها لكن بنفس الثيم» | السبب غير مذكور بالتحديد |

## ينتظر قرار نورة

| البند | لماذا يحتاج قرارًا |
|---|---|
| الشريطة بين البجعة والظرف مرسومة بالكود (SVG) | تخالف قاعدة «كل التصميم من التوليد». البديل: توليدها (البرومبت في `asset-manifest.md`) أو إزالتها |
| الضو بين الرقبتين والرغوة تحت البجع مرسومة بالكود | تأثيرات إضاءة لا عناصر تصميم، لكن القرار لنورة |
| البجعتان تصيران شفافتين كالأشباح وهما تختفيان | اختيار تصميم، وقد يبدو غير نظيف |
| مدة الافتتاحية حتى ظهور الاسم | ارتفعت إلى نحو ١٠ ثوانٍ |
| صيغة الداعي (ريم أم عائلة العلي) | الغلاف والبطاقة مختلفان |
| رقم واتساب المضيفة | بدونه لا يفتح واتساب |
| تعديلات الداخل من الجلسة الأخرى (الورق، الخريطة، الإنجليزي، رسائل الحضور، الكمبيوتر) | إن لم تطلبها نورة فهي تعديل للداخل بلا طلب |
| النشر: فوري بعد كل تعديل، أم بموافقة | تعارض بين `CLAUDE.md` والقاعدة ١٠ |
