# استوديو الدعوات

تعليمات العمل الكاملة في `CLAUDE.md` (نص نورة، مع ملحق عن حالة البيئة).

## البنية
```
InvitationStudio/
  CLAUDE.md                  تعليمات الاستوديو
  global-preferences/
    preferences.md           قواعد عامة صريحة + مرشّحات غير مؤكدة
    preference-history.md    سجل كل تغيير
  projects/
    reem-graduation/         أول مشروع طُبّق عليه الاستوديو
```

## بدء دعوة جديدة
1. اقرأ `global-preferences/preferences.md` (القواعد فقط، لا المرشّحات).
2. أنشئ `projects/<اسم-المشروع>/` بنفس ملفات مشروع ريم.
3. اتبع المراحل في `CLAUDE.md`: الموجز، ثم أربع هويات بلوحات أصول، ثم الانتظار، ثم التثبيت والقائمة والتوليد والبناء والفحص.
4. لا تنقل رفضًا من مشروع آخر إلا إن كان عامًا صراحةً.
