# خطُّ الرجعة

نسخٌ محفوظةٌ من الدعوة، كلُّ واحدةٍ قائمةٌ بذاتها: افتحها في المتصفّح
فتشتغل بلا خادمٍ ولا شبكة. الرجوعُ إلى أيّ نسخةٍ نسخُ ملفٍّ واحد.

| الملفّ | ما هو |
|---|---|
| `2026-08-23-approved.html` | **آخرُ نسخةٍ معتمدة** قبل تغيير الخلفيّة المولَّدة. الفتحُ أفقيّ، والمطرُ ست عشرة ورقة، والخلفيّةُ بدرجات الوردة، والعدّادُ يشتغل. |
| `2026-08-23-approved-netlify.zip` | النسخةُ نفسها جاهزةً للرفع على نتلفاي (index + banner + icon + ‎_headers‎). |
| `blue-fixed.html` | الزرقاءُ بعد إصلاحاتها — أرشيف. |
| `blue.html` | الزرقاءُ الأولى قبل التعديلات — أرشيف. |
| `trial-dress-cream.html` | تجربةٌ لونيّةٌ بخلفيّةٍ أوف وايت سكّريّة — أرشيف. |

## الرجوعُ خطوةً واحدة

```
cp invitation/versions/2026-08-23-approved.html invitation/index.html
```

ثمّ ارفعي `2026-08-23-approved-netlify.zip` على نتلفاي، فيعود الرابطُ
الحيُّ إلى ما كان في اللحظة نفسها.

## الرجوعُ عبر git

كلُّ نسخةٍ معتمدةٍ موسومةٌ بوسمٍ يحمل تاريخها:

```
git tag -l                                     # عرضُ الوسوم
git show approved-2026-08-23:invitation/index.html > /tmp/old.html
git checkout approved-2026-08-23 -- invitation/index.html
```

الوسمُ لا يتحرّك ولا يُحذف، فهو أوثقُ من الفرع.

التغيير ليس حفظًا — المطلوبُ ضاع قبل أن يُنسخ.
